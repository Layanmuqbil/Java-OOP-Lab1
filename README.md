# Java OOP Lab 1 - Video Club Management

This project is a Java implementation of Object-Oriented Programming (OOP) concepts for a Video Club management system.

## Key Concepts Implemented:
* **Classes & Objects:** Defining attributes and constructors for entities.
* **Inheritance:** Creating subclasses (`Customer`, `Owner`) from a superclass (`Person`).
* **Array Management:** Managing a collection of objects (`Film`) within the `Organize` class.
* **Functionality:** Searching for movies by title and displaying details.

## Classes Included:
1. `Person`: Base class for personal details.
2. `Customer` & `Owner`: Specialized classes using Inheritance.
3. `Date`: Custom date class.
4. `Film`: Class representing movie details.
5. `Organize`: Management class for the films array.
6. `Lab1`: Main class to test all functionalities.
